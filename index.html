Features

Everything running on localhost, in one place

Click the plug in your menu bar, or press ⌥⌘P from anywhere.

Every port, with the project behind it

DevPort reads open ports straight from macOS and matches each one to its process, folder and framework. You see 3000 · Next.js · launchbuddy, not node 48213.

  • Detects Next.js, Vite, Rails, Django, FastAPI, Express, Postgres, Redis and more
  • Shows CPU, memory and how long each server has been up
  • Flags dev servers still running after you closed their terminal

“Why is port 3000 busy?” answered

Open any port to see exactly why DevPort thinks it belongs to that project, whether it's reachable from your network or the internet, and whether it's safe to stop.

  • Warns when a port is exposed through ngrok or Cloudflare
  • Spots two processes fighting over one port, including the IPv4/IPv6 split
  • Opens the project in Finder, VS Code, Cursor, Zed or your terminal

Stop or restart safely, in one click

Stop sends a polite signal first and offers Force Quit only if the process ignores it. Restart runs your original command again, like npm run dev, in the right folder.

  • macOS system processes are protected from accidental stops
  • Checks the process is still the same one before sending any signal

Start and stop whole projects

Stacks remember the services each project needs: frontend, API, database, cache. Start everything in the right order, or shut it all down when you switch projects.

Containers, tunnels and local domains too

Docker Desktop, OrbStack, Colima and Podman containers show up with their mapped ports. So do ngrok and Cloudflare tunnels, SSH and kubectl port-forwards, and .test domains.
